# Protótipo - Portfólio de Investimentos Saneamento (Aegea)

## Como Executar

1. Baixe todo o conteúdo da pasta `prototipos/`.
2. Abra o arquivo `index.html` em seu navegador (não é necessário servidor local).
3. Navegue entre as páginas usando os links do menu ou botões de navegação.

## Estrutura de Páginas
- `index.html`: Página inicial do protótipo.
- `bloco2-gestao-demandas.html`: Gestão de demandas de serviços e prestadores.
- `cadastro-subbacias.html`: Cadastro e visualização de sub-bacias/setores hidráulicos.
- `simulacao.html`: Tela de simulação do modelo de priorização de investimentos.

## Funcionalidades Principais
- Navegação conectada entre todas as páginas do protótipo.
- Mock de dados e interatividade (modais, seleção de prestadores, etc.).
- Identidade visual fiel à Aegea (baseada no template fornecido).
- Responsividade garantida (desktop, tablet, mobile).
- Acessibilidade básica (uso de aria-labels, foco em modais).

## Demonstração e Apresentação
- Recomenda-se iniciar pela `index.html` e seguir o fluxo sugerido pelo menu.
- Para apresentação: demonstre a navegação, abertura de modais, seleção de prestadores e fluxo de disparo de demandas.
- Os diagramas de fluxo do negócio estão disponíveis no documento de referência (não incluídos em HTML).

## Observações
- O protótipo não requer backend ou banco de dados.
- Todos os dados são mockados e interações são simuladas via JavaScript.
- Caso encontre bugs, recarregue a página e tente novamente.
