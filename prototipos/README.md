# Protótipo - Algoritmo para Priorização de Investimentos SES

Este repositório contém o protótipo inicial do projeto "Algoritmo para priorização de investimentos SES-20260213_164412" para a Aegea, conforme especificado na reunião de 13 de fevereiro de 2026.

## Estrutura do Protótipo

O protótipo é composto por páginas HTML conectadas, simulando as principais funcionalidades e fluxos do sistema de priorização de investimentos em esgotamento sanitário. A navegação entre páginas e funcionalidades foi implementada para refletir o fluxo de trabalho esperado, conforme as instruções do usuário e o contexto do projeto.

### Páginas Criadas

- **Contato - Aegea.html**: Página de contato institucional da Aegea, utilizada como template visual e de identidade.
- **(Outras páginas devem ser listadas aqui conforme forem criadas no decorrer do projeto, detalhando suas funções e conexões.)**

### Funcionalidades Simuladas

- Navegação entre páginas conectadas, garantindo que ações em uma página possam encaminhar o usuário para funcionalidades presentes em outra página, conforme o fluxo do protótipo.
- Estruturação de telas para cadastro de sub-bacias, componentes, simulação de cenários e visualização de resultados, conforme descrito nas reuniões e requisitos do projeto.
- Simulação de upload de dados (por exemplo, via Excel), visualização de tabelas, filtros e botões de ação para simulação.
- Uso de tabelas e formulários para entrada e edição de dados.

### Tecnologias Utilizadas

- **HTML5**: Estruturação semântica das páginas.
- **CSS3**: Estilos herdados do template institucional da Aegea, incluindo links para folhas de estilo originais.
- **JavaScript**: Scripts para simulação de interatividade básica e navegação entre páginas.
- **Bibliotecas de terceiros**: Incluídas conforme presentes no template base (Elementor, JetEngine, etc.).

### Como Visualizar o Protótipo Localmente

1. Clone ou baixe este repositório em sua máquina.
2. Navegue até a pasta `prototipos/`.
3. Abra o arquivo `Contato - Aegea.html` (ou outra página inicial do protótipo) em seu navegador de preferência.
4. Navegue pelas páginas utilizando os links e botões disponíveis para simular o fluxo do sistema.

**Observação:**
- Para garantir a identidade visual, todas as páginas replicam as tags `<link>` e `<script>` do template institucional da Aegea.
- Caso utilize funcionalidades que dependam de backend ou dados reais, estas estarão simuladas ou desabilitadas neste protótipo estático.

### Observações Gerais

- O protótipo foi desenvolvido com foco em acessibilidade básica (uso de `alt` em imagens, navegação por teclado nos menus) e boas práticas de HTML semântico.
- As páginas e funcionalidades serão expandidas conforme o avanço do projeto e novas etapas do plano de ação.
