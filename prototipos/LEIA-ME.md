# LEIA-ME - Prototipo Priorização de Investimentos Aegea

## Instruções de Execução

1. **Descompacte o arquivo `Prototipo_Priorizacao_Investimentos_Aegea_v1.0.zip` em uma pasta local de sua preferência.**
2. **Abra o arquivo `prototipos/bloco2-gestao-demandas.html` em seu navegador web preferido (Google Chrome, Firefox, Edge, etc).**
3. **Não é necessário servidor web ou instalação de dependências; o protótipo funciona apenas com arquivos estáticos.**
4. **Para melhor experiência, utilize resolução mínima de 1280x720.**
5. **Todos os estilos e scripts são carregados via CDN conforme o template Aegea. É necessário conexão à internet para visualização correta dos estilos.**

## Estrutura da Pasta

- `bloco2-gestao-demandas.html` — Página principal do protótipo
- `CHANGELOG.md` — Registro de mudanças e limitações
- `LEIA-ME.md` — Este arquivo, com instruções de uso

## Observações
- Este protótipo utiliza apenas dados fictícios (mockados) e não realiza integração com sistemas reais.
- Para dúvidas ou sugestões, consulte o time responsável pelo projeto.
